# ASA HostManager — letöltés

ARK: Survival Ascended szerverek kezelése Linux gépeken (Windows app).

**Letöltés:** a [Releases](../../releases/latest) oldalon a legfrissebb
`ASA_HostManager_Setup_<verzió>.exe`. Futtasd, és kövesd a telepítőt.

- A telepítő nincs digitálisan aláírva, ezért a Windows SmartScreen első
  alkalommal figyelmeztethet („Ismeretlen közzétevő”): **További információ →
  Futtatás mindenképp**.
- Az app magától jelzi, ha új verzió érhető el, és egy kattintással frissít.
  A beállításaid és a fiókod megmaradnak.

Ez a tároló csak a kiadásokat tartalmazza.
